# gitbash-mcp 目标与进度

> 当前：M1–M4 首版完成，2.6.0 已发布；下一步：本机更新与客户端加载。设计与契约见 [DESIGN.md](DESIGN.md)，代码职责见 [REPO_MAP.md](REPO_MAP.md)。

## 1. 项目目标

- 为 Windows AI 客户端提供可靠的 Git Bash 执行能力。
- 命令失败可诊断，长任务可找回，风险操作可解释，调用可审计。
- 需要确认的命令由服务器请求本机人类批准，单次批准后执行原请求。
